# 더쎈토익 성적 이미지 메이커

성적 캡처에서 총점을 읽고, 반과 수강 정보를 선택해 1080×1080 PNG 카드뉴스를 저장하는 정적 웹사이트입니다.

## Vercel 배포

이 저장소를 Vercel에서 가져오면 `vercel.json` 설정으로 `dist` 폴더를 배포합니다. 별도의 빌드 명령이나 환경 변수는 필요하지 않습니다.

## 파일

- `dist/index.html`: 입력 화면
- `dist/app.js`: 성적 인식, 카드 렌더링 및 PNG 저장
- `dist/laurel-badges.png`: 월계수 장식

OCR은 브라우저에서 Tesseract.js로 실행합니다. 업로드한 성적 캡처는 서버에 저장하지 않습니다. 폰트와 OCR 라이브러리 로딩에는 인터넷 연결이 필요합니다.
